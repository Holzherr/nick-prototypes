# Learnings

Append-only. One line per gotcha: `- <date> <role>: <what turned out to be true>`. Read before building; append when something non-obvious cost you time.

- 2026-09-11 Nick: the Pages custom domain is set through the API (gh api -X PUT repos/Holzherr/qeued/pages -f cname=qeued.com); workflow deploys ignore the CNAME file.
- 2026-09-19 runner: git pushes to GitHub stall on HTTP/2 from these machines; set http.version=HTTP/1.1 per clone.
- 2026-09-20 builder: catalogue_candidates.status has four values, not three: pending, held, failed and skipped (0020). published_share in agent_snapshot counts skipped as not held, as QD-001 defines it; candidates.by_status carries the split.
- 2026-09-20 builder: in watch-tonight the tone axis means fit with the mood asked for, not the viewer's history, so a client ranker must score it that way or the mood chips change nothing; src can import supabase/functions/_shared/ranking.ts by relative path under Vite, tsc and Storybook with no alias.
- 2026-09-24 builder: JustWatch UK has no page for Vargtimmen under either name (only /us/ does) and Dekalog resolves under its own name, so neither needs an alias tonight; the translated-search fallback (d65e7e9) already reaches most original-language titles. An alias earns its keep where the leading search result is a remake or namesake with the wrong year: Hotaru no haka (the 2005 remake leads). Write aliases from `candidates.mjs failed`, not from guesses.
- 2026-09-25 builder: the builder's worktree has no YAML parser (no yaml package in node_modules; python and ruby are not permitted), so a workflow file kept under qeued-next/tools/ci/ can only be checked structurally here. The real check is a hand run with dry_run ticked from the Actions tab once Nick has copied it.
- 2026-09-25 builder: availability.mjs runs its sweep at import (top-level `await run()`, `process.exit` on `--sql`), so nothing in it can be imported by a test or another tool without restructuring it; refresh-stale.mjs spawns it and carries its own copy of the stale predicate.
- 2026-09-25 builder: `npm test` only picks up `src/**/*.test.ts`, so a tool's test lives in `src/test/` and imports the `.mjs` under a `@ts-expect-error`, because tsc has no declaration for plain JS and `check-types` runs with implicit any forbidden.
- 2026-09-27 builder: a dry run of the weekly availability workflow with 0 stale titles writes no `offers.sql`, so the upload-artifact step must carry `if-no-files-found: warn` or the run fails on a missing file rather than passing (56c09bc).
- 2026-09-27 builder: expand.mjs --gather needs neither a key nor QEUED_DB_URL and touches no table, so a workflow step can probe JustWatch UK from the hosted runner with a fixed fixture and fail before a wave runs; The Godfather (1972), Spirited Away (2001) and Breaking Bad (2008) all resolve from a dev machine.
- 2026-09-27 builder: tsconfig.app.json has no node types, so a test that reads a migration imports it with Vite's `?raw` suffix (household-access.test.ts) rather than node:fs; managed profiles are inserted with is_public false (HouseholdScreen.addManagedProfile), which is why keying the public-profile read policies on profile_id hides a child's list.
- 2026-09-29 builder: the Supabase CLI is not in package.json (tools/db.mjs runs it as `npx --yes supabase@latest`), so a workflow pins it on the npx call (`supabase@2`); supabase/functions holds eight functions plus _shared, not the six the README Backend section counts.
- 2026-09-30 builder: supabase/functions holds nine functions plus _shared (backfill-posters, enrich-title, get-popular, get-recommendations, issue-agent-token, mcp, oauth, search-titles, watch-tonight, each with index.ts, all present since 2026-09-12), not eight as the 2026-09-29 line says.
- 2026-10-04 builder: adding a section to agent_snapshot means `create or replace` with the whole body copied (about 80 lines), so one new section costs most of a 150-line PR; 0027 copies the 0025 sections without their comments and its test compares the two bodies with full-line comments stripped.
