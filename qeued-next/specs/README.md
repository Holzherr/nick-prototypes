# qeued — specs

Shared watchlist and recommendations: watched, watching, want to watch, dropped; ratings; households; "Watch Tonight" picks three from a mood. Live at https://qeued.com. Source is `qeued-next/` of Holzherr/nick-prototypes; the workflow in Holzherr/qeued builds and serves it. Brand is lowercase `qeued`, never capitalised.

Read first: [README.md](../README.md) (stack, scripts), [DESIGN.md](../DESIGN.md). Catalogue is our own scraped data, ranking in `_shared/ranking.ts`, corrections through `tidy.mjs` with a reason.

Backlog, inbox and ledger: https://github.com/Holzherr/agent-team/tree/main/apps/qeued. Board: corral, "qeued".
