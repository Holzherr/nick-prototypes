# Learnings

Append-only. One line per gotcha: `- <date> <role>: <what turned out to be true>`. Read before building; append when something non-obvious cost you time.

- 2026-09-18 Nick: publishing takes two workflow runs (publish, then pages-build-deployment); cache-bust index.html or you read a stale bundle.
- 2026-09-19 runner: git pushes to GitHub stall on HTTP/2 from these machines; set http.version=HTTP/1.1 per clone.
- 2026-09-20 runner: the keychain is unreadable over SSH and from launchd; secrets for headless runs live in ~/.config/agent-team/env on the iMac.
- 2026-09-20 builder: Playwright is not a project dependency and must not become one; `npx playwright screenshot --browser=chromium --viewport-size=390,844 <url> out.png` against `npm run preview` works, and the built Storybook serves any story at `storybook/iframe.html?viewMode=story&id=<title-slug>--<story-slug>`, so screens with state (paused, windDown) are screenshotted from stories rather than by driving the app.
- 2026-09-20 builder: the Builder sandbox has no psql or Postgres and docker/npm-install into /tmp are permission-gated, so a migration's "runs cleanly" criterion is checked by reading, not by running; Nick's SQL-editor paste is the first real run.
- 2026-09-20 builder: the Builder sandbox auto-denies any Bash with subshells, `||`, `$?` or `${…}` expansion; capture exit codes with one plain `cmd >/dev/null 2>&1 && echo EXIT0` per check, run in parallel. Guest play records `earned` level events in its local cache, so an import that only adds its own event silences inference and flattens the timeline unless those events are copied too.
- 2026-09-20 builder: PostgREST refuses an insert that names a column the table does not have even when the value is null, so a not-yet-migrated optional column is left out of the row rather than sent as null (MG-001 names reporter/kind only when chosen, and retries without them).
- 2026-09-20 builder: in the Builder sandbox a Bash line with `$?`, `PIPESTATUS`, a chained `echo` or a `>>` append is permission-gated and denied unattended; run each check as one plain command, read the tool's own exit status, and append to files with the editor.
- 2026-09-20 builder: Storybook 10 rejects `parameters.viewport.defaultViewport` (Section.stories.tsx still uses it, silently ignored); a per-story width is `globals: { viewport: { value, isRotated } }` with any extra size added under `parameters.viewport.options`. jsdom has no `window.matchMedia`; a component that reads a breakpoint through it must treat its absence as the wide layout, and a test stubs `window.matchMedia` per width.
- 2026-09-21 builder: a sheet's QR deep link calls `play()` from an effect while `screen.name` is still `home`, so "started from the home screen" cannot be read from the screen state; what home offered travels as an argument from `GardenHome`'s `onPlay`. `track()` is off on localhost, which is jsdom's default URL; a test that needs the real `track` (the guest early return) sets `// @vitest-environment-options { "url": "https://maths.example/" }` and mocks `@/shared/supabase/client` instead.
- 2026-09-22 builder: a `language sql` function body is parsed against the live schema when `create or replace` runs, so a snapshot migration that names a column an earlier migration adds (0010 reads 0007's `reporter`/`kind`) fails at creation on a database missing that migration and leaves the previous function in place; the header must say which migration it runs after. The README still records 0007 as written, not applied, and nothing in the repo says whether it is.
- 2026-09-24 builder: the eight-per-pack assumption lives in `unlock.test.ts` (exact id lists for the first three packs, `stickerTotal(allAt(1))` is 24) and `milestones.test.ts` (unicorn draw after seven owned returns `stickers[7]`), not in `catalog.test.ts`; growing a pack fails those four tests, so an item that changes pack size must put both files in scope.
